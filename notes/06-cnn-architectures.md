# 第六章：训练 CNN 与经典架构

> CS231n 2025 Lecture 6，2025-04-17，Zane Durante。本讲课件实际还包括归一化、Dropout、激活、初始化、数据处理与迁移学习，不能只背网络名称。以下推导和例子为学习补充。

## 1. 这一章如何接上卷积？

第五章讲了卷积这种运算，但“会搭一个卷积层”和“能够训练好整个网络”之间还有距离。本章可以分成三条线：

1. 保持信息与梯度的尺度合适：归一化、激活与初始化。
2. 有效地组织网络：AlexNet、VGG、Inception、ResNet 等设计思路。
3. 利用有限数据：增强、迁移与训练诊断。

阅读时先理解每个组件解决什么问题，再记典型架构。

## 2. Batch Normalization：归一化什么？

先看一维特征 x₁,…,x_B。训练时计算：

$$\mu_B=\frac1B\sum_i x_i,\qquad
\sigma_B^2=\frac1B\sum_i(x_i-\mu_B)^2,$$
$$\hat x_i=\frac{x_i-\mu_B}{\sqrt{\sigma_B^2+\varepsilon}},\qquad
 y_i=\gamma\hat x_i+\beta.$$

γ、β 是可学习参数，允许网络调整标准化后的尺度和偏移。BN 不会强迫所有后续特征永远均值 0、方差 1。

对 CNN 的 N×C×H×W 激活，通常对每个通道，在 N、H、W 这些轴上统计；每个通道有自己的 γ、β。

**算例：** 一维批量 [1,3]，均值 2、方差 1，忽略 ε 后标准化为 [−1,1]。若 γ=2、β=1，输出为 [−1,3]。

训练中通常还维护均值与方差的移动统计。推理时使用这些统计，而不是依赖当前测试批次。因此切换 train/eval 模式会改变 BN 行为。具体框架对方差估计的细节可能不同，本章公式是概念定义。

BN 往往有助于优化，但不能保证修复错误初始化或所有梯度问题；把它的全部作用归因于“内部协变量偏移”也过于简单。

### 与 LayerNorm 区别

作为与后续 Transformer 衔接的补充：LayerNorm 通常对单个样本或单个 token 的特征维度归一化，不依赖别的样本。BN 和 LN 的区别首先是统计轴，不是一个更高级、一个更低级。

## 3. Dropout：训练时随机屏蔽部分激活

设保留概率 q，掩码 m_j∼Bernoulli(q)。常用的 inverted dropout 为：

$$\tilde h_j=\frac{m_jh_j}{q}.$$

这样 E[ h̃_j ]=h_j。训练时有的激活归零，保留下来的乘 1/q；推理时不丢弃，也不再缩放。

例：h=[2,4]、q=0.5、一次掩码 [1,0]，输出为 [4,0]。这是一次随机结果，不等于期望值。

课件也展示过“训练直接丢弃、推理时缩放”的约定。两种约定不能混用，否则尺度会错。

Dropout 可以降低某些特征之间的过度依赖，但并不是越多越好，也不是每个 CNN 都必须使用相同位置和比例。

## 4. 初始化：为什么不能把所有权重都设成零？

如果同一层的隐藏单元具有完全相同的初始权重，在对称结构中会收到相同梯度、学到相同特征，无法有效发挥宽度优势。随机初始化用于打破这种对称性。

随机数也要有适当尺度：过小可能让信号逐层缩小，过大可能让激活和梯度失控，或者把 sigmoid/tanh 推到饱和区。

常见近似规则：

- Xavier 类初始化：围绕输入输出维度控制方差，例如 2/(fan_in+fan_out)。
- He 初始化：对 ReLU 类层常用 Var(W)=2/fan_in。

fan_in 是一个输出单元接收的输入数量；卷积中通常是 C_inK_hK_w。

为什么 ReLU 出现系数 2？在对称、近似独立等假设下，ReLU 会使二阶矩约减半，因此初始化适当放大来补偿。它是近似的尺度分析，不是所有架构的严格方差保证。

例如输入维度 100，He 正态初始化的标准差为 √(2/100)≈0.1414，而不是 0.02。偏置设零通常没有上述整层权重全零的对称性问题。

## 5. 经典架构：每种设计贡献什么？

| 架构 | 阅读重点 | 不必第一遍记住的内容 |
|---|---|---|
| AlexNet | CNN、大规模数据与 GPU 训练的历史突破 | 每一层的所有数字 |
| VGG | 重复堆叠小卷积核形成深网络 | 不同变体的逐层编号 |
| Inception / GoogLeNet | 多分支处理不同尺度，并用 1×1 降低成本 | 每个分支的全部通道配置 |
| ResNet | 学残差并保留捷径连接，改善深网络优化 | 所有深度版本的参数量 |

本版正文主要展开 AlexNet、VGG 与 ResNet；表中 Inception 的设计说明是帮助理解历史图谱的补充。

架构的历史成绩要理解为当时数据集、训练配置和评测条件下的结果，不是今天所有任务的性能排名。

### VGG 为什么喜欢 3×3？

同通道宽度 C、无偏置时，一个 5×5 卷积有 25C² 个权重；两个 3×3 卷积共有 18C² 个，并形成 5×5 理论感受野，还可以在中间增加非线性。

这依赖输入、中间、输出通道相同等假设。小核堆叠与大核不是完全等价函数，也不能只凭参数少断言运行一定更快。

### ResNet 的关键公式

$$y=x+F(x).$$

F(x) 表示卷积、归一化、激活等组成的残差分支。如果需要的变换接近恒等映射，残差分支只需要学一个接近 0 的修正。

![残差块与梯度路径](../assets/remaining/06-residual.png)

其导数包含：

$$\frac{\partial y}{\partial x}=I+\frac{\partial F}{\partial x}.$$

恒等项为信息与梯度提供直接路径，但并不保证梯度永远不会消失或爆炸。

相加的两条分支必须形状相同。如果通道数或分辨率改变，可以使用投影捷径 y=P(x)+F(x)，P 常用 1×1 卷积并配合步长。

## 6. 数据预处理与增强

常见图像预处理是按通道减均值、除标准差：

$$x'_{c,h,w}=\frac{x_{c,h,w}-\mu_c}{\sigma_c}.$$

从头训练时，用训练集计算统计量，避免把测试集信息带入选择过程。使用预训练模型时，通常应遵循该模型训练时的预处理约定，包括像素范围、通道顺序、均值和标准差。

数据增强不是改变标签的任意变换，而是要求变换后目标语义仍成立。例如自然图像分类常用裁剪和水平翻转，但识别左右方向、文字或医学侧别时，翻转未必保留标签含义。

训练时可使用随机增强；验证时通常使用确定流程，方便比较。检测和分割任务变换图片时还必须同步变换框与掩码。

## 7. 迁移学习：已有特征怎样复用？

先在大数据集预训练，再为新任务调整：

**只训练分类头：** 冻结骨干，使用它提取特征，训练新输出层。成本较小，但无法充分适应很不同的目标数据。

**微调部分或全部网络：** 从预训练参数开始继续训练。常给骨干较小学习率、新分类头较大学习率；这是实践策略，不是定理。

决定冻多少层，要考虑目标数据量、源目标差异、算力与验证表现。小数据并不意味着无条件冻结全部层，大数据也不意味着必须从头训练。

冻结权重不自动保证 BN 的运行统计不变化；需要同时明确模块模式与统计更新行为。

## 8. 看训练曲线怎样诊断？

| 现象 | 可能原因 | 下一步检查 |
|---|---|---|
| 训练损失几乎不降 | 学习率、梯度、标签、预处理可能有问题 | 先尝试在很小的数据子集上拟合 |
| 训练变好、验证持续变差 | 可能过拟合或分布差异 | 增强、正则化、早停及数据划分 |
| 损失明显发散或 NaN | 步幅过大或数值异常等 | 输入范围、损失实现、梯度尺度 |
| 训练与验证差距异常 | 模式切换、增强或泄漏问题 | BN、Dropout、重复样本 |

这些是排查线索，不能仅凭曲线形状唯一确定原因。先排查实现与数据，再靠大规模调参掩盖错误。

## 9. 复习摘要

一套 CNN 的表现由结构、初始化、优化、数据与预处理共同决定。归一化管理尺度，残差改善信息路径，增强与迁移改善数据利用；没有任何一个组件能替代其余工作。
