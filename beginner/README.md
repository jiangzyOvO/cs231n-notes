## 阅读时只做三件事

1. **先找输入与输出。** 不清楚一个数组表示什么时，先看形状和一行数据，不急着背公式。
2. **跟着一个小例子算。** 本路线尽量复用同一组数字；例子改变时会重新说明输入、损失和假设。
3. **最后回到专业笔记。** 基础路线讲清主线，课程正文提供更完整的范围，不必同时打开十几个文件。

正文中的“先记住”是核心关系；“易错提醒”解释容易混淆的地方。粗体、表格、引用块和图片均使用 GitHub 可展示的格式；所有图片都有文字说明，不能显示图片时也能阅读。

## 数值与符号约定

- 批量矩阵采用**每行一个样本**：`X` 为 `(N, D)`，线性层为 `X @ W + b`。
- 单张图像默认使用**通道 × 高 × 宽**；加批次后为 `N×C×H×W`。遇到视频和点云会重新解释轴。
- `@` 是矩阵乘法，`*` 是 NumPy 逐元素乘法；二者不能互换。
- 分类使用 Softmax 交叉熵；为便于手算，部分例子使用平方误差，都会说明是求和还是平均。
- “网络输出”和“模型参数”是不同对象；“反向传播”和“更新参数”是不同步骤。

本路线的数值例子可在仓库根目录运行：

```bash
python3 experiments/guided_examples.py
```

只需 Python 标准库。脚本核验教学算例，不下载数据，不代表真实图像模型训练。
