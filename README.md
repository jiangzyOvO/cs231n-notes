## 学习方式

1. 预习：明确本讲要解决的问题。
2. 学习：结合官方课件讨论直觉、公式与例子。
3. 验证：用小练习、推导或实验检查理解。
4. 整理：记录自己的解释、错误原因及尚未解决的问题。
5. 复习：不看笔记复述，再回查遗漏。

以理解情况决定速度，不照搬课程日历。学习起点和每周投入时间待确定；尚未完成任何讲次。

## 文件约定

- `notes/`：每讲学习笔记，文件名采用 `01-introduction.md` 等形式。
- `experiments/`：小实验及结果说明。
- `templates/`：统一笔记模板。
- `PROGRESS.md`：进度与复习状态。
- `QUESTIONS.md`：个人疑问与解决记录。

原始记录、待核实解释和已验证结论应明确区分。实验记录输入、运行方法、结果和局限，不把预期结果当作实际运行结果。
